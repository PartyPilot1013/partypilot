# PartyPilot

Plan a party in minutes: describe it, pick food, decorations and drinks, see a live budget, and get shopping lists split by store.

## What's here

- `index.html` – the whole app (no build step)
- `manifest.json`, `sw.js`, `icon-*.png` – lets people add it to their phone's home screen

## Run it locally

Open `index.html` in a browser, or run `npx serve .` and visit the address it prints.

## Deploy

Import this repo at vercel.com/new. No settings needed: it's a static site.

Prices are estimates. Store buttons currently open a store search; one-tap carts need the Instacart Developer Platform and an alcohol partner (e.g. ReserveBar).
